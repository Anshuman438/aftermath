# AFTERMATH

> Turn production failures into reproducible tests.

## Monorepo Architecture

- `aftermath-sdk/` — Capture SDK (Java library)
- `aftermath-collector/` — Collector Service & Database
- `aftermath-ui/` — Web Dashboard (React + Vite)
- `aftermath-replay/` — Replay Engine
- `aftermath-testgen/` — Test Generator
- `aftermath-cli/` — CLI Tool
- `sample-app/` — Demo Application (Payment & Coupon Microservices)
- `docs/` — Specifications & Architecture Docs
